## 知识主线

15 天实际是一条链：

> 认识目标（1-2）→ 看清防护与拓展面（3-4）→ 延伸到移动端（5）→ 学会抓包看流量（6-7）→ 拿下控制权（8-9）→ 看懂数据与加密（10-11）→ 读懂协议与鉴权（12-13）→ 站稳脚跟操作权限（15）

## 分板块笔记

### 1. Web 应用架构认知（Day 1-2）

- **域名差异**：主站、分站（blog.x.com）、端口站（:88）、目录站（/bbs/）、子站（a.blog.x.com）——不同形态意味着资产边界不同。
- **源码差异**：语言（PHP/Java/Python/JS...）、框架（ThinkPHP/Spring/Django/Vue...）、开源/闭源/加密型。
- **数据差异**：本地库、分离库、云数据库（RDS）。
- **六种 Web 架构与测试思路**：套模板站重用户权限；前后端分离打 API 与前端 JS；集成包（宝塔/phpstudy）看防护与权限；Docker 容器想进程逃逸提权；纯静态无 Web 漏洞只能找资产。
- **五种源码形式**：简易源码、MVC 框架、编译封装（.NET-DLL / Java-Jar）、前后端分离、加密型——做代码审计前先判断手里源码的真实形态。

### 2. 防护与拓展面（Day 3-4）

- **WAF**：常规测试手段会被拦截（演示用雷池社区版）。
- **CDN**：隐藏真实源 IP，测试容易打错目标。
- **OSS**：上传文件存到云存储、不落地无法解析——但 AK/SK 泄漏是隐患。
- **反向代理 / 负载均衡**：访问目标可能只是代理；负载均衡意味着多个后端目标。
- **蜜罐（HFish）**：钓鱼诱捕测试者的防护系统，扫到"弱口令"先想想是不是坑。
- **堡垒机（Jumpserver）**：反过来是高价值信息突破口。
- **API 接口**：分析目录结构、接口与参数命名规则，做接口枚举和参数枚举。

### 3. 移动应用（Day 5）

- APP 四种开发架构：原生（Java/Kotlin）、H5、Flutter、Web 壳。
- 小程序：原生 / WebView / 框架 / 低代码。
- 通用测试路数：**反编译提源码 → 提取泄漏的配置信息 → 抓包测接口**。

### 4. 抓包技术（Day 6-7）

- 工具矩阵：Burp、Yakit、Reqable（抓包+接口测试二合一）、Fiddler、Charles、Proxifier。
- 证书信任三件套：浏览器、模拟器、真机都要装。
- APP 抓包：无防护走模拟器；有防护走真机绕过 / 证书绕过 / 代理绕过。
- **工具链联动**：Burp → Yakit → Reqable 通过上游下游代理串联，一个包过多个引擎。
- **双层代理**：Clash + Burp 解决"目标需要梯子才能访问还要抓包"的场景。
- **全局协议抓包**：Wireshark / 科来——应对检测代理设置就拒绝工作的应用、TCP/UDP 流量分析。

### 5. 网络控制（Day 8-9）

数据不回显与不出网，是渗透里最经典的两个死局，这套课给了标准解题框架：

- **不回显五招**：反弹权限、数据带外（DNSlog / TCP / ICMP）、延迟判断（ping -n / -c）、写可访问文件、按环境灵活处理。
- **不出网三招**：正向连接（能进不能出时）、反向连接（能出不能进时）、协议隧道（ICMP/DNS）。
- 判定流程：判断出入限制 → 判断限制的端口和协议 → 再决定用正向、反向还是隧道。
- 反弹 Shell 生成器：revshells.com、forum.ywhack.com/shell.php 等；Windows 基本靠 PowerShell，Linux 几乎全能弹。

### 6. 数据与加密（Day 10-11）

- **传输格式**：JSON / XML / WebSocket / 二进制 / 自定义——Payload 必须适配目标格式。
- **三大类算法与解密条件**：
  - 单向散列（MD5/SHA）：密文即可，碰撞解密，看明文复杂度；
  - 对称（AES/DES/RC4）：需要密文 + Key + 偏移量 + 模式；
  - 非对称（RSA）：需要密文 + 公钥或私钥。
- **密文特征速判**：MD5 是 16/32 位十六进制；Base64 尾部常有等号；AES/DES 密文常出现 `+` 和 `/`；RSA 长度更长。
- **有源码看逻辑，无源码扒前端 JS**：加密逻辑若在前端，直接复用目标自己的 JS 加密函数发送 Payload，让测试流量符合业务逻辑。
- 典型案例：Discuz `md5(md5($password).$salt)` 的字典碰撞脚本。

### 7. 协议与鉴权（Day 12-13）

- **状态码研判陷阱**：网站容错处理会让错误页面返回 200（误报）；3XX 跳转有"中间件规则"和"代码跳转"两种来源，目录扫描不能只看状态码。
- **红队视角**：UA 头可能是注入点（收集 UA 入库的场景）、Cookie 是身份、Post 数据是爆破位、状态码做文件探针。
- **鉴权选型场景**：Cookie+Session 内网、Token 跨域、JWT 做单点登录、OAuth 做第三方授权。
- **OAuth2 攻击面清单**：redirect_url 校验不严导致 code 劫持、code 跨应用滥用、state 缺失引入 CSRF、scope 提权、HTTP 劫持、点击劫持。
- Authorization 头家族：Basic / Digest / Bearer / JWT / API Key / 2FA。

### 8. 系统与权限（Day 15）

- Bat 批处理：for 循环 + ping 做 C 段存活扫描。
- Shell 入门：grep/sed/awk 统计 SSH 爆破日志、Web 日志中的 SQL 攻击事件——蓝队基本功。
- Windows 权限：完全控制 / 修改 / 读取执行等文件权限体系，Administrators / System / TrustedInstaller 等用户组。
- Linux 权限：uid 分配原则（0 管理员 / 1-999 系统账号 / 1000+ 普通用户）、/etc/passwd 与 /etc/group 字段解读、rwx 对文件和目录的不同含义。
